# Антифрод-система Nexign

Система скоринга телефонных вызовов по метаданным без прослушивания разговора. Разработано для хакатона Nexign командой "Падабук".

## Описание
ML-модель (CatBoost) определяет вероятность мошенничества исключительно по техническому "конверту" звонка, не нарушая приватность абонентов. 

**Ключевые особенности:**
- **Анализ метаданных:** длительность, страна, тип соединения, баланс входящих/исходящих.
- **Графовые и поведенческие признаки:** выявление веерного обзвона, аномальной географии и низкой кластеризации контактов.
- **Объяснимость (SHAP):** система не просто выдаёт риск, а показывает оператору *топ-факторы*, повлиявшие на решение (например, "80% звонков короче 3 сек").
- **Жёсткая защита от ложных срабатываний:** многоуровневый White List (экстренные службы 101-112, банки, госуслуги, операторы связи), который гарантирует, что легитимные вызовы никогда не будут заблокированы.

## Быстрый старт

Для запуска проекта **не требуется Docker**. Достаточно Python 3.9+ и трёх окон терминала.

### 1. Установка окружения и зависимостей
Откройте терминал в корневой папке проекта:
```bash
# Создаём виртуальное окружение
python3 -m venv venv

# Активируем его (для macOS/Linux)
source venv/bin/activate
# (Для Windows используйте: venv\Scripts\activate)

# Устанавливаем библиотеки
pip install -r requirements.txt
```

### 2. Обучение модели (выполняется один раз)

Этот шаг автоматически сгенерирует синтетический датасет (имитирующий реальные телеком-данные с учётом паттернов мошенников и легитимных ловушек) и обучит модели CatBoost для сценариев "до ответа" и "после вызова".

```bash
python -m antifraud.train
```

После завершения в папке models/ появятся файлы .cbm, а в reports/ — отчёт о метриках (AUC > 0.99).

### 3. Запуск API (Бэкенд)
Откройте второе окно терминала, активируйте окружение (source venv/bin/activate) и запустите FastAPI-сервер:

```bash
uvicorn antifraud.api:app --port 8000 --reload
```

### 4. Запуск интерфейса (Фронтенд)
Откройте третье окно терминала, активируйте окружение и запустите Streamlit:

```bash
streamlit run antifraud/app.py
```


## Как протестировать (Демо)
В интерфейсе Streamlit предусмотрены готовые сценарии для быстрой демонстрации жюри:

    Нажмите "🕵️ Мошенник" → система покажет высокий риск и объяснит его факторами (веерный обзвон, короткие сбросы).
    Нажмите "👤 Обычный" → система покажет низкий риск и сбалансированную историю.
    Нажмите "🚑 Экстренная служба" → система гарантированно покажет риск 0 и пометку White List, демонстрируя защиту от ложных блокировок.
